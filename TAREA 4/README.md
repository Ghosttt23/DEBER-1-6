# TAREA 4 - Colas

## Enunciado
Implementar la funcion `contarElementos`.

## Implementacion
Funcion: `contarElementos(const Nodo* frente)` (`Operaciones.h` / `Operaciones.cpp`)

Recorre la cola de frente a fin con un contador, sin modificarla. Devuelve 0 si la cola esta vacia.

Se agregaron llamadas de prueba en `main.cpp`.

## Compilar
```
g++ Nodo.cpp Operaciones.cpp main.cpp -o programa
```
